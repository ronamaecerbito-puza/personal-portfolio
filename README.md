# Personal Portfolio Website

A responsive, dark-themed portfolio inspired by the layout and feel of the reference site.

## Preview
Open `index.html` in your browser.

## Customize before publishing
Search and replace these sample details in `index.html`:
- `Your Name` / `YOUR NAME` / `YN`
- Course, school, location, and personal introduction
- Skills and project names/descriptions
- Email address (`your.email@example.com`)
- LinkedIn and GitHub profile URLs
- Timeline dates and achievements

You can change colors near the top of `style.css` in the `:root` section.

## Publish for free with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the published URL shown in the Pages settings.

This is a static site; contact uses the visitor's email app through a `mailto:` link.
